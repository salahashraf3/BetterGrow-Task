# Bettergrow Sales Dashboard

A small web app for tracking salesperson sales against budget (Bettergrow Holding Group practical assessment).

## Prerequisites

- Node.js 20.19+ or 22.12+ (required by Vite 8)
- npm 10+

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm test
npm run test:run
```

- `dev` — local development server
- `build` — production TypeScript check and bundle
- `lint` — strict ESLint
- `test` — Vitest in watch mode
- `test:run` — Vitest once (CI-friendly)
